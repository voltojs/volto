# 配置模型并开始第一次对话

> 读完你会：配好一个模型供应商，选择工作区，让 agent 改一次代码。

## 前提

网关与 Web 界面已经在跑（见 [安装并启动](./01-install.md)）。

## 步骤

### 1. 打开设置 → 模型配置

点左下角的设置按钮，选「模型配置」。这里管理供应商与它们下面的模型。

### 2. 添加一个供应商

点「添加供应商」，两种类型选一种：

- **内置目录**：从内置的供应商目录里选（Anthropic、OpenAI 及一批兼容厂商），只需填 API Key，模型清单可从目录自动补全。
- **自定义**：自己填一个 OpenAI 兼容端点（base URL）和模型 ID，适合自建网关或私有部署。

填完点保存。**API Key 加密后存在服务端**（`~/.volto/config.json` 的 `providers` 分区），不会进入浏览器存储。

你应看到：供应商卡片出现在列表里，展开后能看到它下面的模型。

### 3. 选中要用的模型

在供应商卡片里启用至少一个模型；回到聊天页，用输入框上方的模型选择器选中它。

### 4. 选择工作区

点顶部的工作区选择器，选一个本地目录（或新增一个）。agent 的文件读写、命令执行都以它为工作目录——它不是「可访问范围」的限制，见 [权限与审批](../guides/permissions-and-approvals.md)。

### 5. 发第一句话

在输入框里写一句具体的任务，例如：

```text
通读这个仓库的 README，用三句话说明它是做什么的，然后把结论写进 NOTES.md。
```

按回车。你会看到模型输出、工具调用（读文件、写文件），以及需要你点头的审批卡。

## 你应看到的结果

- `NOTES.md` 出现在工作区里。
- 右侧或折叠面板里能看到这次改动涉及的文件与 diff。
- 顶部上下文用量条有数值（表示这一轮消耗了多少上下文）。
