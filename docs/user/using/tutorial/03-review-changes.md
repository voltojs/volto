# 看懂改动、审批与恢复会话

> 读完你会：知道 agent 每一轮到底改了什么、什么时候它在等你点头、关掉窗口后怎么接着聊。

## 一轮里会发生什么

1. 你发一句话，agent 决定要不要调用工具（读文件、搜代码、跑命令、改文件）。
2. 需要你同意的动作会弹出**审批卡**，卡住等你的选择。
3. 改文件时，改动以 **diff 卡片**的形式挂在对应消息下。
4. 一轮结束，你可以继续追问，或新开一段对话。

## 审批卡

审批卡上写明要执行什么、为什么。你的选择：

- **允许一次**：只放行这一次。
- **拒绝**：agent 会收到拒绝结果并换一种做法，不会卡死。
- **始终允许…**（仅对合格的 `bash` 命令出现）：把这条命令前缀记进 `~/.volto/config.json` 的 `permissions.rules`，**下一轮起**对所有项目生效。回报里会写清是否真的写入、以及为什么没写。

想让某类操作不再打扰，又不想放宽整体权限，去 [权限与审批](../guides/permissions-and-approvals.md) 配规则。

## 计划模式

输入框里发 `/plan 目标`，会话进入计划模式：**只读调研**，产出计划文档让你审。批准后再执行。

计划模式下 agent 只能读、不能改；产出的是计划本身，写在会话自己的计划文档里，不写你的工作区。

## 改动在哪看

- **diff 卡片**：跟在这一轮的工具调用下面，按文件列出增删行。
- **「文件」面板**：列出这一轮动过的文件，可在文件树 / 预览 / diff 之间切换。
- **「Git」面板**：工作区状态、diff、提交图与分支切换。

面板的收起按钮在顶栏最右端，收起后用聊天顶部的「展开面板」重新打开。面板状态按会话记忆：切换会话时恢复各自的面板，回到旧会话时它的子代理 / 计划页签原样恢复，详见 [子代理与后台任务](../guides/subagents-and-tasks.md)。

## 接着上次聊

会话持久化在 `~/.volto/` 下。关掉浏览器、重启前端都不影响：左侧列表点回去就是原来的上下文。

- 标题由首条消息生成；可在「设置 → 通用设置」指定一个便宜的模型专门起标题。
- 上下文满了会触发压缩（老消息折叠成摘要）。也可以用 `/compact` 手动触发一次。

## 出问题怎么办

- **审批卡一直不出现，界面卡在「审批等待中」** → 网关与前端连接断了，刷新页面后重新发一次该请求。
- **模型报 4xx** → 供应商/模型配置或 Key 有问题，回「设置 → 模型配置」检查。
