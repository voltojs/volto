# 斜杠命令与输入技巧

> 读完你会：知道 `/` 菜单里每个命令做什么，以及 `@` 和附件怎么用。

## 命令表

| 命令 | 作用 | 谁执行 |
| --- | --- | --- |
| `/plan [目标]` | 进入计划模式：只读调研，先产出计划等你批准 | 前端 |
| `/clear` | 新建一段会话（当前上下文不带走） | 前端 |
| `/compact` | 手动压缩当前会话的上下文 | 前端 |
| `/review [范围]` | 让 agent 评审改动，按严重度列出问题与修法；不给范围时看未提交改动 | 网关模板 |
| `/explain [对象]` | 让 agent 讲清某个实现与关键代码路径 | 网关模板 |
| `/技能名` | 调用一个技能（只列出允许用户主动调用的） | 网关 |

区分「谁执行」很重要：

- **前端的三个命令**（`/plan` `/clear` `/compact`）在本地生效，**不会**变成一条消息发给模型——所以 `/clear` 不会产生一轮对话。
- **网关模板**（`/review` `/explain`）会把命令展开成一段完整的提示词再发给模型——发出去的是展开后的内容，不是 `/review` 这几个字。
- `/clear extra` 这类带多余参数的写法不算命令：它会被当成普通消息发给模型，内容被归一化成 `Unknown command: /clear. Available commands: …`，所以模型看到的是「这个命令不存在」而不是「清空会话」。

## 输入技巧

- **`@` 引用文件**：输入 `@` 会弹出工作区文件列表，选中即插入一个文件引用。引用在发送时会被解析成文件内容或路径，比手打路径可靠。
- **图片**：直接粘贴或拖进输入框。能不能被模型看见取决于该模型是否声明了图片输入（见 [模型与供应商](../guides/models-and-providers.md)）。
- **多行**：`Shift + Enter` 换行，`Enter` 发送。
- **打断**：一轮跑太久，点停止按钮（真实效果是中断当前回合，已产生的内容保留）。
- **排队**：正在跑的时候继续输入，消息会排队在下一轮送出，而不是被丢弃。

## 自己加命令

`/review` 与 `/explain` 是网关内置模板；更多模板可以直接在消息里写完整的提示词——命令只是省打字，没有别的魔法。技能（skill）是另一套机制：放在项目或用户目录下，由 agent 自己判断何时加载。
