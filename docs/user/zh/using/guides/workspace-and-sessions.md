# 工作区与会话

> 读完你会：知道工作区是什么、会话存在哪、怎么找回和清理它们。

## 工作区

工作区就是 agent 干活的那个目录。选中它之后，文件读写、命令执行、git 操作都以它为工作目录。

- 工作区列表存在 `~/.volto/config.json` 的 `projects` 分区（`id` / `name` / `path` / `createdAt`）。
- 同一个工作区可以开很多段会话，它们共享文件系统，但对话上下文彼此独立。
- **工作区不是安全边界。** 它决定「默认在哪干活」，不决定「能碰什么」——那由权限档位与沙箱决定。见 [权限与审批](./permissions-and-approvals.md)。

## 会话

每段对话是一段持久化的记录，落在 `~/.volto/` 下的会话库里（JSONL，逐条事件追加）。

| 能力 | 怎么做 |
| --- | --- |
| 找回 | 左侧列表按工作区分组；关掉浏览器、重启前端都不丢 |
| 重命名 | 会话菜单 → 重命名；标题也可由模型自动生成（设置里可指定专用模型） |
| 置顶 | 会话菜单 → 置顶。置顶状态存在网关侧，换浏览器也一致 |
| 删除 | 会话菜单 → 删除会话。正在生成中的会话不可删 |
| 导出 | 会话菜单 → 导出会话（Markdown）；接口还支持 JSONL |
| 回退到某一轮 | 从该轮之前的对话起点新建一段会话，原会话保留 |
| 压缩 | `/compact` 手动触发一次上下文压缩 |
| 刷新后恢复 | 浏览器本地记住当前激活的会话；刷新后自动回到它，会话不存在时回欢迎屏 |

正在生成的会话会在标题左侧显示旋转图标；即使你切到别的会话，这个图标仍保留，直到该回合结束。

侧边栏布局（置顶、工作区顺序、排序方式、折叠状态）单独存在 `config.json` 的 `sidebar` 分区。它是**视图状态**，不写进对话记录——否则导出一段对话会连带把「置顶」也带出去。

## 附件与文件引用

- **图片**：直接粘贴或拖进输入框。能不能被模型看见取决于该模型是否声明支持图片输入。
- **非图片附件**：PDF、文本等会被转成文本块并入消息（PDF 默认最多解析 50 页、约 20 万字符，超出部分会说明被截断）。
- **`@` 引用**：输入 `@` 从工作区选文件，插入一个文件引用；引用在发送时解析成路径或内容，比手打路径可靠。

附件按会话隔离存放。会话被删除后，其附件目录由后台清理任务在 24 小时宽限期后回收；仍存在的会话的附件永不回收。

## 审计轨迹

每段会话除了对话本身，还有一份**审计轨迹**：每一步的输入、工具调用、审批决定、上下文提醒都按时间记录。界面里的轨迹视图就是它的投影，用来回答「它当时为什么这么做」。

每次模型调用的“请求”Tab 会列出这次请求的结构：模型、header hash、工具名、消息 id/role、内容块类型、工具调用/结果 id 和图片附件 ref。它不保存完整文本和图片字节，所以能看到请求由什么组成，但不会把大段 prompt 或截图塞进轨迹。旧会话在升级前没有这份清单，请求 Tab 会显示为空。

原始事件也可以直接取（`GET /sessions/:id/events`），导出的 JSONL 与它同源。

## 会话快照存在哪（sqlite 与回退）

会话快照默认写在 `~/.volto/db/sessions.db`（SQLite）。它依赖原生模块 `better-sqlite3`，在换了 Node 版本、缺预编译二进制的机器上可能载不进来。这时 Volto **不会**清空或迁移这个库，而是：

1. 启动时打印一条警告，明确写出现在用哪个目录存新会话、哪个库文件不再被读取；
2. 改用 `~/.volto/sessions-store/` 下的文件存储，会话照常可用；
3. `volto doctor` 的 `sqlite` 一行显示 `warn (file (fallback: module missing))`。

如果驱动装好了、但库文件本身打不开（权限、被占用、文件损坏），同样改用文件存储，但 `doctor` 显示的是
`warn (file (fallback: db unusable))`，警告里会写明**这个库确实存在、只是没被读取**，并带上底层错误码。
两种情况都不会删除或改写 `sessions.db`。

原来的 `sessions.db` 原样躺在磁盘上，问题修好后再启动就会重新被读取。`doctor` 正常时这一行是 `sqlite: ok (sqlite (primary))`。如果你确知当前环境的 sqlite 不能用，可以设 `VOLTO_SESSION_STORE=file` 显式使用文件存储，`doctor` 会显示 `file (forced)`。

## 出问题怎么办

- **会话列表里少了一段** → 检查是不是换了工作区目录（列表按工作区分组）；或者 `volto doctor` 的 `sqlite` 一行是不是 `file (fallback: …)`——那表示旧会话还在 `sessions.db` 里，只是当前进程没读它。
- **点开会话报读不了**（接口返回 410，提示该会话由更早的版本写入）→ 当前构建读不了它；用能读它的版本导出后重开。
- **附件不见了** → 会话被删过，附件随之清理。附件不跨会话复用。
